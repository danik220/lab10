## Висновок
У ході лабораторної роботи №10 було опановано роботу з мережевими утилітами CLI (`systeminfo`, `ping`, `tracert`, `netstat`), розроблено BASH-скрипт `lab.sh` для автоматизованого створення каталогів, заповнення файлів даних, використання регулярних виразів для перевірки email та фільтрації лог-файлів Apache. Проєкт успішно інтегровано з GitHub Actions.
